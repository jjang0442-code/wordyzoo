# 워디 주 (Wordy Zoo)

6~10세 아이를 위한 영어 단어 동물원 게임 (웹앱 / PWA).

- 접속: https://jjang0442-code.github.io/wordyzoo/
- 폰에서 "홈 화면에 추가"하면 앱처럼 설치되고, 한 번 들은 소리는 오프라인에서도 재생돼요.

## 구성
- `index.html` — 게임 전체 (화면, 그림, 단어·문장 데이터)
- `audio/` — 단어·문장 녹음 (mp3)
- `sw.js` — 오프라인 지원
- `manifest.webmanifest`, `icons/` — 홈 화면 설치용
